# IME Editor — 日本語IME内蔵テキストエディタ (HTML + JavaScript)  v1.14

ブラウザだけで動く、日本語IMEを内蔵した秀丸風テキストエディタです。
IMEは **形態素解析ベースの連文節変換**(ラティス + Viterbi、Mozc互換のコスト体系)で、キー操作はATOK準拠、エディタ操作は秀丸準拠です。

変換辞書は Mozc のオープンソース辞書(BSD-3)だけを同梱しています。**ATOK の辞書ファイル(.DIC)をお持ちの場合は、
起動後に「その他→変換辞書→辞書ファイルの取り込み」で選ぶと、ブラウザ内で変換して使えるようになります**(下記)。

## ATOK 辞書ファイルの取り込み (v1.4)

1. その他→変換辞書 を開き、[辞書ファイルの取り込み...] で `.DIC` / `.dic` を選びます(複数選択可)。
   ATOK Pro 4 なら ATOK30.DIC(標準辞書)、ATOK30NM.DIC(人名)、ATOK30TK.DIC(単漢字)、ATOK30KG.DIC(記号)、ATOK30TR.DIC(トレンド)、
   ATOK30CS/SE/LE.DIC(専門用語)など。医療辞書'07(Atk_MD*.dic)も取り込めます。
2. ファイルはその PC のブラウザ内で解析・変換され、IndexedDB に保存されます(外部には送信しません)。標準辞書で数秒です。
   次回以降は保存済みのデータを読み込むだけなので、辞書ファイルは不要です。
3. 取り込んだ辞書は一覧に追加され、チェックで ON/OFF、[削除] で消去できます。取り込み直後の既定は、標準・人名・単漢字・記号・
   トレンド・専門用語が ON、カタカナ語英語・日本語英語・町名住所・郵便番号・医療辞書が OFF です。
4. 文字コード辞書・IVS辞書・部首変換辞書など、かな漢字変換用でない辞書は取り込めません(その旨を表示します)。

- 保存先はブラウザ×開き方(file:// と http://localhost は別)ごとです。ブラウザのサイトデータを消すと取り込んだ辞書も消えるので、その場合は取り込み直してください。
- 取り込み時だけ `dict/mozc_cal.js`(Mozc 全語のコスト表、16MB)を読み込みます。ATOK の辞書には頻度情報がないため、Mozc にも載っている語は
  その品詞ID・コストを使い、ATOK 固有の語は品詞ごとの基本コストを付けます。動詞・形容詞は語幹から活用形を生成します。
- 解析できるのは ATOK Pro 4(ATOK30 世代)と医療辞書'07(2005〜2008年頃の形式)で検証した形式です。他の版の辞書は取り込めない場合があります。
- **辞書の内容は各権利者(ジャストシステム、オフィス21 など)の著作物です。正規のライセンスをお持ちの方が、ご自身の辞書を
  ご自身の PC で使う用途に限ってください。** 変換後のデータの再配布はできません。

設定ダイアログ(動作環境・変換辞書)は [OK] で反映、[キャンセル]/✕/Esc で変更せずに閉じます。

## 使い方

1. フォルダごと置いて `index.html` を **Chrome または Edge** で開く(ダブルクリックでOK。file:// で動きます)。
   GitHub Pages などに置いても同じように動きます(※後述の注意)。
2. **OS側の日本語入力(MS-IME / ATOK)は OFF** にしてください(半角/全角キー)。
   ONのままだとOSのIMEが先にキーを取ってしまいます(その場合ステータスバーに警告が出ます)。
3. 起動後 2〜3 秒で辞書が読み込まれます(ステータスバー「辞書 1/1」。辞書を取り込むと数が増えます)。
4. ローマ字で入力 → Space で変換 → Enter で確定。キー一覧は F1。

## IMEの仕組み (参考記事「開発陣が語るGoogle日本語入力」の方針に沿った実装)

| 段階 | 実装 |
|---|---|
| ローマ字→かな | ATOK互換テーブル(nn/n'→ん、促音、拗音、ふぁ/てぃ/ゔ 等)。`@`始まりは英字のまま(医療辞書の略語) |
| 辞書 | 読み→項目(表記, 左右文脈ID, コスト, コメント)。読みでハッシュ検索、前方一致は整列済みキーの二分探索 |
| 連文節変換 | 読み全体のラティスを作り、単語コスト + 接続コスト(Mozc接続表)の最小経路を Viterbi で求める。未知語はひらがな/カタカナ/英数ノードで補う |
| 文節化 | 助詞・助動詞・接尾・非自立・記号は前の自立語に付属。接頭詞は次語と結合。サ変名詞+する も1文節 |
| 候補列挙 | 注目文節の範囲で経路をビーム探索(左右の文節との接続コスト込み)し表記で集約。末尾に ひらがな/カタカナ/半角カナ 候補 |
| 文節伸縮 | 境界を1文字ずらし、残りを再変換 |
| 学習 | 確定した文節(読み→表記)と単語を localStorage に保存。次回から候補先頭/コスト優遇 |
| 推測変換 | 学習履歴 + 辞書の前方一致。Tab で選択、Shift+Enter で確定 |
| 単語登録 | Ctrl+F7。ユーザー辞書は localStorage。ATOK単語ファイル形式で書き出し/取り込み可 |

### ATOK 辞書の組み込み方 (tools/build_dicts.py)

ATOK の辞書には頻度情報が入っていないので、コストは次のように決めています。
- 同じ(読み, 表記)が Mozc 辞書にある語 → Mozc の品詞ID・コスト(頻度に基づく)をそのまま使う。
- ATOK にしかない語 → 品詞ごとの基本コスト(名詞 6500、固有名詞 7000、地名 7300、単漢字 7800 …)から語長に応じて少し引く。
  よく使う語は Mozc 側のコストで上位に来て、ATOK 固有の語(地名・人名・専門用語・複合語)はそれを補う形になります。
- 動詞語幹(五段は属性の「行」コード、一段、形容詞語幹)から活用形(基本形・未然形・連用形・連用タ接続・仮定形・命令形)を生成し、
  Mozc の活用形IDを付けて登録(「温め直す」「相照らす」などの複合動詞が変換できます)。
- 単漢字辞書の「非印刷標準字体」は +500、記号はコメント(Unicode名)なしのものを少し後ろに。
- 医療辞書07 は、一般辞書にも載っている語に医療語ボーナスを付ける従来どおりの設定(既定OFF。ONにすると 受診/受信 などで医療語が優先されます)。

## ファイルタイプ別の設定 と 動作環境 (v1.9)

秀丸と同じく、設定画面は2つに分かれています。どちらも左の「設定の対象」でページを切り替え、[OK] で反映・保存、[キャンセル] で破棄します。

- **その他→ファイルタイプ別の設定** (Configuration for each file type): フォント / 体裁(折り返し) ・タブ(2/4/8/指定、タブキーで空白入力) ・インデント(自動インデント) /
  デザイン(場所の一覧と文字の色・背景の色・スタイル、リセット、配色の保存/読込) ・表示1(改行文字・EOF・タブ文字・全角空白の表示) ・表示2(ルーラー・行番号表示・カーソル行)
- **その他→動作環境** (Environment): ファイル(新規ファイルの文字コード・改行・BOM) / 表示/操作(ステータスバー、テーマ) / Markdown / かな漢字変換(IME) / 音声入力 / 環境(表示言語)

「デザイン」では、場所の一覧から項目を選び、文字の色・背景の色のボタンで「色の指定」ダイアログ(基本色48色、システム・背景色/文字色、色合い×鮮やかさの面と明るさバー、HSL/RGB の数値入力、OK/キャンセル)を開きます。
一覧のチェックは表示の ON/OFF で、表示1・表示2 のチェックと連動します。「保存/読込」で 白背景 / 黒背景(秀丸風) / ダークグレー / クリーム / 緑背景 を一括設定できます。
英語モードの用語は秀丸の英語版に合わせています(Form, Showing1, Places, Assigned color, Return code character など)。

## 罫線 (v1.10)

OASYS 風に、修飾キーを押しながら矢印キーでカーソルを動かすと、通った跡にテキストの罫線が引かれます。

| キー | 動作 |
|---|---|
| Alt+矢印 | 細線を引く(─│┌┐└┘├┤┬┴┼) |
| Alt+Shift+矢印 | 太線を引く(━┃┏┓┗┛┣┫┳┻╋)。細線と交差すると ┿ ╂ ┠ ┨ ┯ ┷ などを自動で選びます |
| Alt+Ctrl+矢印 | 罫線を消す |

角・T字・十字は、線のつながり方から自動で決まります。既存の文字の上を通るとその桁(全角1文字ぶん)が罫線に置き換わり、行が短ければ空白で埋め、最終行より下へ進むと行が追加されます。
マクロ→罫線 で「全角罫線 / 半角罫線(+-|)」を切り替えられ、「表に行を挿入」はカーソル行の縦線を引き継いだ空の行をすぐ下に作ります。1歩ごとに Ctrl+Z で戻せます。
罫線文字は全角幅(2桁)として扱うので、等幅の日本語フォントで表示してください。

## キー配列 (v1.12)

その他→動作環境→環境→キー配列 で、エディタのキー操作を切り替えられます。割り当ての一覧は F1 で表示されます。

| 配列 | 主な内容 |

| 秀丸エディタ (標準) | これまでどおり |

| Atom | Ctrl+↑↓ 行移動、Ctrl+Shift+D 行複製、Ctrl+J 行連結 など |
| Emacs | C-f/b/n/p、C-a/e、M-f/b、C-k / C-y、C-Space・C-w・M-w、C-x C-s、C-x C-f、C-/ など (Esc はメタキーとして使える) |
| vi / Vim | ノーマル/挿入/ビジュアルの 3 モード。移動、d y c > < とテキストオブジェクト、p、u、.、/ ? n N、:w :q :%s など |
| nano | ^K / ^U、^O、^X、^W、^\、^_、M-U / M-E など |
| VZ Editor | ダイヤモンドカーソル (^E ^X ^S ^D)、^Q・^K の 2 ストローク、^Y / ^J のテキストスタック など |

- かな漢字変換の入力中・変換中は、どの配列でも IME (ATOK 準拠) のキーが優先されます。

- Ctrl+N・Ctrl+T・Ctrl+W は通常のタブではブラウザが処理します。表示→全画面表示 (F11) の間はエディタに届きます (Keyboard Lock API、Chrome / Edge)。
- VS Code / Atom 配列では Alt+↑↓ などが行の移動に使われるので、罫線は マクロ→罫線→罫線モード (矢印キーだけで描く) を使ってください。
- vi の検索・置換は JavaScript の正規表現です。レジスタ、マーク、マクロ (q)、矩形ビジュアルには対応していません。

## 表示言語 (v1.8)

その他→動作環境→環境 の「表示言語/Display language」で 日本語 / English を切り替えられます([OK] で即時反映、再読み込み不要)。
メニュー・ダイアログ・ステータスバー・メッセージが切り替わります。対訳表は `js/i18n_en.js`(日本語の文字列 → 英語)で、訳の修正や追加はこのファイルだけで行えます。
英語メニューでは下線付きの英字が Alt キー操作の文字です(Alt+F → File、X → Exit)。

## 音声入力 (v1.3, Web Speech API)

- ステータスバーの 🎤、`Ctrl+Alt+M`、または その他→音声入力 で ON/OFF。認識途中の文字は点線下線でカーソル位置に表示され、確定するとその位置に挿入されます(キーボード入力と併用可)。
- 認識方式(その他→動作環境→音声入力): **端末内のみ**(既定。音声を外部に送らない。Chrome 139 以降＋日本語言語パック約60MB、同じ画面からインストール) /
  端末内優先 / クラウド(Chrome は Google、Edge は Microsoft のサーバーに音声が送られます。患者情報などを話す用途には使わないでください)。
- 音声コマンド: 「かいぎょう」→改行、文末の「まる」→。、「てん」→、。句読点の種類・全角数字・半角カナは IME の入力既定に従います。
- **再変換**: 誤認識した語を選択して `変換` キー(または `Ctrl+Alt+R`)で、内蔵IMEの辞書から同音の候補を出して置き換えられます(例: 受信した→受診した)。Esc 2回で元に戻ります。初回のみ逆引き索引の作成に1秒ほどかかります。
- マイク許可が file:// で出ない場合は、フォルダで `py -m http.server 8000` を実行して `http://localhost:8000/index.html` を開いてください。

## Markdown (.md) サポート

- `.md` / `.markdown` を開くと自動で Markdown モード(表示→Markdownモードで固定も可)
- 見出し・リスト・チェックボックス・引用・コード・リンク・強調・表の **構文色分け**
- アウトラインバー(メニュー下)に現在の見出しを表示、クリックで **見出し一覧** からジャンプ
- 表示→**Markdownプレビュー** で右側にプレビュー(スクロール連動、黒配色対応)。GFM の表・タスクリスト・フェンスコードに対応
- 編集→Markdown: 太字/斜体/取り消し線/コード/コードブロック/リンク/見出しレベル/箇条書き/番号付き/チェックリスト/チェックON-OFF/引用/水平線/**表の整形**(列幅を揃える)
- ファイル→**HTMLとして書き出し** でスタイル付き HTML を保存

## 同梱辞書の再生成 (必要な場合)

```
py tools/build_dicts.py <Mozc辞書フォルダ> - - dict      # general.js / mozc_cal.js / connection.js / posdef.js / manifest.js
```
Mozc辞書は https://github.com/google/mozc の `src/data/dictionary_oss/`(dictionary00〜09.txt, id.def, connection_single_column.txt)。
`tools/atokdic_dump.py` は辞書ファイルを TSV に書き出す単体ツール(js/dictimport.js と同じ解析)です。

## 注意・制限

- 同梱しているのは Mozc 辞書(BSD-3-Clause、dict/LICENSE-mozc.txt)だけです。取り込んだ ATOK 辞書のデータは利用者のブラウザ内にのみ保存され、配布物には含まれません。
- 変換精度は ATOK や Google日本語入力には及びません(言語モデルが単語bigram相当で、ATOK の連想・文脈処理や頻度情報は再現していない)。
  学習と単語登録で補ってください。
- ブラウザ固有のショートカット(Ctrl+N 新規ウィンドウ、Ctrl+T、Ctrl+W)は横取りできません。新規はメニューの「新規作成」を使ってください。
- 「終了」はブラウザの制約でタブを閉じられない場合があります(その場合はタブを手で閉じてください)。
- 縦書き・矩形選択・マクロ・grep など秀丸の高度な機能はありません。
- 数万行を超えるファイルは初回描画に数秒かかります(2万行で約1秒)。
